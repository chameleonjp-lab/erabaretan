# エラバレタン：P4-03 H2人間試遊手順

- 文書状態：Draft PRで実行準備
- 候補："candidate.p4-03.h2"
- 試遊数：最低8試合
- 通常WebへのH2混入：なし
- 通信・保存・計測：なし（Pages配信時の通常のアクセス記録は除く）

## 1. このPRで守ること

H2は、星砕きの解放時の世界損傷を7から8へ変更した実験候補です。通常の公開content index、web/generated、通常Webの入口にはH2を追加しません。試遊版はtrials/p4-03-h2/だけに置きます。

試遊版は、候補名とビルド元コミットSHAを画面上部へ表示します。8個の固定seedを順番に使い、各試合のseedと先攻を表示します。試合後の記録欄から内容をコピーできますが、外部へ自動送信しません。

## 2. マージ後の公開手順

このDraft PRをマージした後、次の順に操作します。

1. GitHubのSettings → Environmentsでh2-human-trial環境を作り、必要なら自分を承認者に設定する。
2. Actions → H2 human trial Pages → Run workflowを開く。
3. Branchはmain、Operationはpublishを選び、実行する。
4. 承認画面が出たら内容を確認して承認する。
5. 実行結果のSummaryに出るH2試遊URLをiPhone Safariで開く。

URLを知っている人はアクセスできます。検索結果へ載せにくくする指定は入れますが、認証ではありません。

## 3. iPhoneでの試遊

タイトル画面で候補名とビルド元SHAを確認し、世界律画面の固定場面表示を確認します。

その後、最低8試合を行います。画面には次を表示します。

- 試遊番号
- 固定seed
- 先攻
- 終了種別
- ラウンド数
- 75境界へ到達したか

各試合の結果画面で、次の5問に短く答え、「この試合の記録をコピー」を押します。

1. 75境界が、カードを選ぶ理由として理解できましたか？
2. 星砕きの解放は、使いたい行動として魅力的でしたか？
3. 星砕きの抑制が、毎回の正解に感じられませんでしたか？
4. 75境界の直前で、試合が長く停滞しませんでしたか？
5. 神の選定者を、結果前にある程度予想できましたか？

コピーできない場合は、iPhoneのスクリーンショットやメモで残します。記録に、試合番号・seed・先攻・終了種別・ラウンド・75境界の到達状態を含めてください。

## 4. 試遊後の削除

8試合以上の記録を保存したら、同じworkflowをもう一度実行します。

- Branch：main
- Operation：cleanup

完了後、先ほどのURLが404になることを確認します。URLを知っている人が閲覧できる状態を長く残さないため、削除確認を試遊の完了条件にします。

## 5. 次の判断

人間試遊の記録を確認した後、Sol・Highが独立レビューを行います。正式なruleset.alpha-12.v2やattack.star-breaker.v2への昇格は、独立レビューが終わるまで行いません。
