# 選ばれたん：ゲーム企画・アイデア設計書

- 文書状態：初期企画版
- 対象：最初の1対1版と、その後の拡張
- 更新日：2026-08-09

## 1. この文書の目的

本書は、対戦カードゲーム「選ばれたん」の世界観、遊びの中心、勝敗、カード構造、画面体験、バランス上の注意点を定める。

この段階では個々の数値を完成値として固定しない。まず、どの選択が面白さを生み、どの状態を失敗とみなすかを明確にする。数値は自動対戦と人間による試遊で調整する。

---

## 2. 一文で表す企画

> 神に選ばれた戦士たちが、授けられた力で生き残りを争いながら、世界へ与えた損傷と再生の責任まで神に査定される対戦カードゲーム。

相手を倒しただけでは、正式な勝者になれるとは限らない。

生き残るために世界を壊すのか。自分を危険にさらして世界を守るのか。試合中の行動を、最後に神がまとめて評価する。

---

## 3. 世界観

### 3.1 基本設定

世界は崩壊の兆候を見せている。

神は次の時代を託す戦士を選ぶため、候補者へ超常的な武器、防具、祈り、災害を引き起こす権能を授ける。そして候補者同士を戦わせる。

ただし、神が見ているのは戦闘力だけではない。

神から授けられた力を制御できたか。生存のために世界をどこまで犠牲にしたか。傷ついた世界を回復するために何を失ったか。これらも選定の対象になる。

### 3.2 プレイヤーの立場

プレイヤーは、神に選ばれた戦士候補である。

戦闘中は強力なカードを使うほど有利になりやすい。一方、その力が大地、空、生命、時間などを壊す場合、世界損傷として記録される。

世界を回復する行動は評価を上げるが、多くの場合は手番、体力、手札、攻撃機会のいずれかを失う。

### 3.3 表現の方針

特定の実在宗教や既存神話をそのまま借りず、固有の神話体系を作る。

雰囲気は荘厳さと不穏さを中心にする。ただし、カード名や結果称号には少し奇妙さを残し、敗北や事故も語りたくなる作品を目指す。

---

## 4. プレイヤーに体験してほしいこと

本作の中心は、次の四つの感情である。

1. 強い神力を解放したい誘惑
2. 世界を傷つけた責任と後悔
3. 自分を危険にさらして世界を回復する覚悟
4. 生存結果と世界への責任が並ぶ、最後の神の審判

単に「世界ゲージを守ると得点が増える」という仕組みにしない。世界の状態が戦闘中にも変化し、その変化が次の判断へ戻ってくる構造にする。

---

## 5. 設計の柱

### 5.1 生存と評価を一致させすぎない

最後まで生き残った戦士は大きく有利になる。しかし、世界を極端に破壊した場合は、死亡した戦士に総合評価で負ける可能性を残す。

この例外が、本作の独自性になる。

### 5.2 世界への損傷は、引いたカードの罰ではなく本人の選択にする

強力な世界損傷カードしか手札にない場合でも、弱い安全使用、封印、破棄などを選べるようにする。

世界を壊した減点は「不運な配札」ではなく、「強い効果を選んだ代償」でなければならない。

### 5.3 相手の番にも判断を残す

攻撃された側は、防御カードを使う、ダメージを受けて温存する、別の資源を消費して防ぐ、反撃条件を満たす、といった選択を持つ。

### 5.4 世界の状態を見れば、次の危険を予測できる

世界が一定値を下回ったときに起きる反応は、試合開始時または直前に予告する。

完全に予測不能な事故ではなく、危険を承知で世界を壊す判断を作る。

### 5.5 1試合ごとの物語を残す

勝敗だけでなく、誰が世界を壊し、誰が回復し、どの力が決定打になったかを結果画面で説明する。

## 6. 最初の完成対象

| 項目 | 初期方針 |
|---|---|
| 対戦人数 | 1対1 |
| 画面 | iPhone縦画面を最優先 |
| 目標試合時間 | 6〜10分 |
| 初期体力 | 30（検証値） |
| 世界耐久 | 100（検証値） |
| 初期手札 | 7枚（検証値） |
| 最大ラウンド | 10〜12ラウンドで検証 |
| 初期カード種類 | 24種類 |

## 7. 一試合の流れ

### 7.1 試合開始

1. 両者の体力を30、世界耐久を100にする。
2. 共有山札を作り、各プレイヤーへ7枚ずつ配る。
3. 今回の試合で発生する「世界反応」を公開する。
4. 先攻を決める。

初期版では、プレイヤーが事前にデッキを組む方式を採用しない。共通のカード群からランダムに配られた手札をどう使うかを中心にする。

### 7.2 自分の手番

1. **世界段階**：継続中のフィールド効果を処理する。
2. **補充段階**：カードを1枚引く。手札上限を超える場合は選んで捨てる。
3. **行動段階**：カードを1枚使う、封印効果で使う、または手札を1枚捨てて終了する。
4. **応答段階**：攻撃された側が防御、反応、受ける、のいずれかを選ぶ。
5. **解決段階**：戦闘効果、世界損傷、世界再生、世界反応を順番に処理する。
6. **終了段階**：暫定評価と次の危険を更新する。

### 7.3 手番時間

最初の検証値は次のとおりとする。

- 通常行動：20秒
- 防御判断：12秒
- 通信切断時の猶予：60秒

時間切れでは、勝手に強力なカードを使わない。通常は「行動しない」または「攻撃を受ける」として安全側に処理する。

---

## 8. カードの分類

ユーザー案の5分類を採用する。ただし、カードは一つの分類だけに閉じない。

### 8.1 主な分類

| 分類 | 主な役割 |
|---|---|
| 攻撃 | 相手の体力、手札、次の行動へ不利益を与える |
| 防御 | ダメージを防ぐ、減らす、受け流す、反射する |
| 世界影響＋ | 世界を回復し、神の評価を上げる |
| 世界影響－ | 世界を傷つける代わりに強力な結果を得る |
| フィールド効果 | 数手番にわたり、試合全体の規則を変更する |

### 8.2 カードは複数の性質を持てる

たとえば「星砕き」は、主な分類が攻撃であり、同時に世界影響－を持つ。

「地脈の誓壁」は防御であり、条件を満たすと世界影響＋も発生する。

画面では、次の順に表示する。

1. 戦闘で何が起きるか
2. 世界へ何が起きるか
3. 誰の評価として記録されるか

### 8.3 世界への数値

すべてのカードは次のいずれかを持つ。

- 世界損傷：0以上
- 世界再生：0以上
- 世界影響なし

世界損傷と世界再生を同時に持つカードも許可する。ただし、意図が一読で理解できないカードは作らない。

---

## 9. 強力なカードの二つの使い方

世界を大きく傷つけるカードは、原則として二つの使用方法を持つ。

### 例：星砕き

**解放する**

- 相手へ16ダメージ
- 世界損傷7

**封印する**

- 今回の攻撃を3防御
- 世界影響なし

これにより、手札にあるだけで減点されることはない。

プレイヤーは「今ここで世界を壊して相手を倒すか」「弱い効果として使い、世界を守るか」を選ぶ。

---

## 10. 世界耐久と世界反応

### 10.1 世界耐久

世界耐久は100から始まり、全プレイヤーで共有する。

| 世界耐久 | 状態 | 表現 |
|---:|---|---|
| 100〜76 | 安定 | 明るい空、正常な大地 |
| 75〜51 | 亀裂 | 空や地面に亀裂が入る |
| 50〜26 | 荒廃 | 建造物や生命が失われる |
| 25〜1 | 崩壊寸前 | 画面全体と音が不安定になる |
| 0 | 終末審判 | 戦闘を終了し、神の評価へ進む |

### 10.2 世界反応

75、50、25などの境界を初めて下回ったとき、世界が戦闘へ反応する。

反応例：

- 最も多く世界を傷つけた戦士へ8ダメージ
- 次の1ラウンド、世界損傷を伴うカードの反動が2倍
- 両者の最大体力が3低下
- 直前に世界を再生した戦士がカードを1枚引く

一度発生した境界反応は、世界を回復して再び下回っても再発しない。

### 10.3 世界崩壊時

世界耐久が0になっても引き分けにはしない。

その場で戦闘を終了し、神の評価へ進む。最後の損傷で世界を0にした戦士には「破界責任」の追加減点を与える。

負けそうなプレイヤーが世界を壊して相手の勝利を消す行動を防ぐためである。

---

## 11. フィールド効果

### 11.1 基本ルール

- 同時に有効なフィールドは1枚だけ。
- 新しいフィールドを使うと、古いフィールドを上書きする。
- 基本持続時間は2〜3ラウンド。
- 継続的な世界損傷または再生は、フィールドを使った本人へ記録する。
- 現在の効果、残り時間、責任者を常に画面へ表示する。

### 11.2 例

**焦土の法**

- 2ラウンド、すべての攻撃力＋3
- 使用時に世界損傷5
- 攻撃が成立するたび、使用者へ世界損傷1を追加記録

**再生の雨**

- 2ラウンド継続
- そのラウンドで世界損傷カードが使われなかった場合、世界再生3
- 使用者へ再生実績を記録

フィールド効果は、説明が長くなりやすい。初期版では、一つのフィールドに主要効果1つと付随効果1つまでを基準にする。

---

## 12. 神の評価

### 12.1 評価項目

最終評価は、ユーザー案の三項目で決める。

1. 生存ポイント
2. 世界へのダメージによる減点
3. 世界の回復による加点

初期の検証式は次のとおりとする。

```text
神の評価
= 生存ポイント
+ 実効世界再生 × 2
- 個人世界損傷 × 3
- 破界責任
```

この式は完成値ではない。試遊で調整する。

### 12.2 生存ポイントの考え方

生存ポイントは、次の要素を合算する。

- 生存したラウンド数
- 終了時の残り体力
- 最後まで生存した場合の大きなボーナス

原則として生存者が有利になる。しかし、世界を極端に破壊した生存者は、世界を守って死亡した相手に負ける可能性がある。

### 12.3 回復点の不正な稼ぎ方を防ぐ

自分で世界を傷つけ、自分で回復して点を稼ぐ行動を防ぐ。

- 回復しても、過去の個人世界損傷記録は消えない。
- 損傷1点の減点を、再生1点の加点より重くする。
- 世界耐久が実際に減っている分だけを「実効世界再生」として記録する。
- 世界耐久100の状態で回復カードを使っても、再生点は増えない。
- 同じ効果を無限に繰り返せないよう、カード循環と回復回数を制限する。

### 12.4 暫定評価

終了時に突然負けたと感じさせないため、戦闘中にも暫定評価を表示する。

ただし、常に大きな数字を並べると戦闘を邪魔する。通常は「現在1位」「破壊責任が大きい」「再生貢献が上回った」などを短く表示し、詳細は開閉式にする。

### 12.5 同点

初期版では同点を引き分けとする。

不透明な乱数や入力速度で勝者を決めない。

---

## 13. 試合終了条件

次のいずれかで戦闘を終了し、神の評価へ進む。

1. 片方または両方の体力が0になった。
2. 世界耐久が0になった。
3. 最大ラウンドに到達した。
4. プレイヤーが降参した。
5. 切断猶予を超えた。

戦闘の勝者と神の選定者を分けて表示する。

例：

```text
戦闘結果：アレスが生存

神の評価：
ガイア 42
アレス 18

神に選ばれた者：ガイア

アレスは戦闘には勝利したが、
世界への損傷が大きく、選定されなかった。
```

## 15. 手札事故への対策

ランダム性は残すが、何も選べない状態は減らす。

- 世界損傷の大きいカードには、安全な代替使用を持たせる。
- 攻撃カードの一部は小さな防御としても使える。
- 防御カードの一部は弱い攻撃または世界再生として使える。
- 手札を1枚捨てて手番を終える選択を認める。
- 同じ役割のカードだけが連続しすぎない山札構成を検証する。

万能カードを増やしすぎてはいけない。どちらに使っても強いカードは、判断をなくすためである。

## 16. 駆け引きの想定

### 16.1 破壊の誘惑

相手の体力が少ないとき、世界損傷7の攻撃で倒せる。しかし、その損傷によって世界反応が発生し、自分も死亡する可能性がある。

### 16.2 回復の隙

世界再生カードを使えば評価は上がるが、その手番は攻撃できない。相手が強力な攻撃を準備している場合、回復が敗因になる。

### 16.3 責任の押し付け

世界耐久が境界直前のとき、自分は中立行動を選び、相手に世界反応を起こさせようとする。

### 16.4 フィールドの上書き

相手が置いた破壊的なフィールドを、安全なフィールドで上書きするか、残り1ラウンドなので手札を温存するかを選ぶ。

## 17. 画面設計

### 17.1 縦画面の基本構成

```text
┌────────────────┐
│ 相手：体力・手札枚数・暫定評価 │
├────────────────┤
│ 世界耐久／世界の見た目          │
│ 現在のフィールド／次の世界反応  │
├────────────────┤
│ 戦闘処理とカード演出            │
├────────────────┤
│ 自分：体力・個人損傷・個人再生  │
│ 手札                           │
│ 決定／取り消し                 │
└────────────────┘
```

### 17.2 操作

カードはドラッグだけで使わせない。

1. カードをタップして拡大する。
2. 解放、封印、防御などの使い方を選ぶ。
3. 対象と世界影響を確認する。
4. 独立した決定ボタンで送信する。

強力な世界損傷カードには、次の確認を出す。

```text
相手へ16ダメージ
世界へ7損傷
あなたの損傷記録 12 → 19

この力を解放しますか？
```

毎回同じ確認でテンポを壊さないよう、危険度が一定以上のカードに限定する。

### 17.3 結果の見せ方

効果は一度にまとめず、原因順に見せる。

1. 攻撃宣言
2. 防御カード
3. 戦闘ダメージ
4. 世界損傷または再生
5. 世界反応
6. 暫定評価の変化

演出を短縮する設定と、動きを減らす設定を用意する。

## 18. 美術と音

### 18.1 世界を主役の一つにする

背景は飾りではなく、共有された世界状態の表示装置として扱う。

- 亀裂が増える
- 空の色が変わる
- 遠景の建造物が崩れる
- 生き物が逃げる
- 再生により植物、光、水が戻る

破壊と再生を同じ素材の色変更だけで済ませず、形、動き、音でも区別する。

### 18.2 音

- 通常攻撃：短く明確
- 世界損傷：低い地鳴りと環境音の欠落
- 世界再生：広がる音と環境音の回復
- 終末審判：戦闘音を止め、評価へ移る間を作る

音は初期状態で切り替え可能にし、無音でも情報を失わない画面にする。

## 19. 初心者向け説明

最初に長い規則文を読ませない。

CPU相手の短い導入で、次の順に体験させる。

1. 攻撃する
2. 防御する
3. 強力なカードが世界を傷つける
4. 世界を回復する
5. 生存者と神の選定者が異なる結果を見る

説明文の中心は次の一文とする。

> 相手を倒すだけでは勝てません。生き残りながら、世界への責任も神に評価されます。

## 20. 想定される失敗と対策

| 失敗 | 起きる問題 | 初期対策 |
|---|---|---|
| 破壊カードを連打すれば勝てる | 世界評価が飾りになる | 損傷減点、世界反応、破界責任を組み合わせる |
| 回復だけで勝てる | 戦闘が進まない | 回復に体力、手番、手札を要求する |
| 自分で壊して直して稼ぐ | 評価が不正に増える | 損傷記録を消さず、損傷の重みを大きくする |
| 世界0で引き分けを狙う | 負け側が試合を壊す | 世界0でも評価を実施し、最後の破壊者を追加減点 |
| フィールドが重なり理解不能 | 現在の規則が分からない | 有効フィールドを1つに制限 |
| 世界損傷を強制される | 減点が本人の判断にならない | 安全な代替使用を持たせる |
| 生存が軽すぎる | 死んで回復点を稼ぐ方が有利 | 生存ボーナスを最大の単一要素にする |
| 生存が強すぎる | 従来の撃破ゲームに戻る | 極端な世界破壊で逆転可能な配点にする |
| 計算が複雑 | 結果に納得できない | 暫定評価と原因別の結果表示 |

## 21. 多人数戦への拡張方針

1対1をそのまま4人へ広げない。

### 21.1 2対2

- チームの体力は共有する案を検討する。
- 世界損傷と再生は個人別に記録する。
- チーム勝利と個人評価が食い違う余地を残す。

### 21.2 3〜4人個人戦

- 早期脱落者が長く待たないラウンド制を検討する。
- 集中攻撃を抑える標的制限または反撃補正を検討する。
- 最後の1人だけでなく、複数ラウンドの神評価で決める。

多人数戦は、1対1のカードと配点が安定した後に別ルールとして設計する。

## 22. 品質確認の基準

初期の検証目標を次のように置く。

| 確認項目 | 仮の合格基準 |
|---|---:|
| 試合時間の中央値 | 6〜10分 |
| 12分を超える試合 | 5％未満 |
| 実質的な選択肢がない手番 | 5％未満 |
| 同じ回復・防御の無限循環 | 自動対戦で0件 |
| 世界評価が勝者を変える試合 | 少なすぎず、多すぎない範囲を試遊で決定 |
| 初心者が基本を説明できる | 2試合以内 |
| 敗因を本人が説明できる | 試遊者の大半 |
| 「もう1戦」を選ぶ割合 | 継続して測定 |

世界評価が毎回勝敗を逆転すると、生存の意味が弱くなる。一方、ほとんど逆転しなければ世界要素が飾りになる。適切な発生率は、実際の試遊で決める。

## 25. 現時点の判断

本作の中心は「環境保護の点数稼ぎ」ではない。

> 生き残るために世界を傷つけるか、自分を危険にさらして世界を守るかを、毎手番の選択にする。

攻撃、防御、世界影響＋、世界影響－、フィールド効果という案を採用しつつ、各カードが戦闘上の役割と世界への責任を重ねて持つ設計にする。

この形であれば、ランダムな手札を処理する対戦カードゲームの分かりやすさを残しながら、最終的な神の評価という独自の判断軸を作れる。
