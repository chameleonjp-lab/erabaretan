## 1. 企画の中心

### 1.1 一文で表す

> 約7分で、相手を倒すか世界を守るかを迫られ、最後に神から戦い方そのものを査定される対戦カードゲーム。

### 1.2 最も短い紹介文

> 戦闘に勝っても、神に選ばれるとは限らない。

### 1.3 プレイヤーへ約束すること

- URLを開き、難しい準備なしで対戦できる。
- ランダムな手札でも、少なくとも二つの使い道を考えられる。
- 強力な力には、戦闘以外の代償がある。
- 世界の状態が、戦闘中のルール、見た目、音へ反映される。
- 結果画面を見れば、なぜ選ばれたか、なぜ選ばれなかったか分かる。
- 一試合ごとに、相手と話したくなる出来事が残る。

---

## 2. 対象者

### 2.1 主な対象

- 5〜10分程度の短い対戦を好む人
- 友人へリンクを送り、すぐ遊びたい人
- デッキ構築なしで、配られたカードへの対応を楽しみたい人
- 運による事件と、自分の判断の両方を楽しめる人
- スマートフォンで片手または両手のタップ操作をしたい人

### 2.2 初期版で狙わない対象

- 長時間のデッキ構築を中心に遊びたい人
- カード収集、課金、育成を中心に遊びたい人
- 運をほとんど含まない競技だけを求める人
- 1試合30分以上の重い戦略ゲームを求める人

### 2.3 利用場面

- 友人と通話しながら数試合
- SNSやメッセージで共有されたURLから一戦
- CPU相手の短い練習
- 限定公開後の合言葉大会

## 3. 世界観

### 3.1 基本設定

世界はゆっくり崩壊している。

神は存在するが、世界へ直接手を入れられない。そこで、次代の守護者候補へ一時的に権能を委ねる。

候補者は、神の権能を使って互いに戦う。

神が見ているのは、単純な強さだけではない。

- 与えられた力を制御できたか
- 自分の生存のために、世界をどこまで犠牲にしたか
- 傷ついた世界を回復するために、何を支払ったか
- 相手の破壊へ、どのように対処したか

戦闘は、世界の守護者を選ぶための審定である。

### 3.2 既存作品との差

本作は、神の後継者や神の座そのものを争う話にしない。

プレイヤーは神になる候補ではなく、世界を託される守護者候補である。

次を独自の中心とする。

- 世界損傷の個人責任
- 世界再生の貢献
- 戦闘勝者と神の選定者の分離
- 世界が戦闘へ介入する世界律
- 力を解放するか抑制するかの選択

### 3.3 表現の調子

- 基本：荘厳、不穏、終末的
- 操作説明：短く、平易
- 結果称号：少し皮肉または奇妙さを含む
- 暴力表現：写実的な流血ではなく、光、亀裂、消失で表現
- 実在宗教：固有の神名、聖典、儀礼をそのまま使わない

## 4. 用語

| 用語 | 意味 |
|---|---|
| 戦士 | プレイヤーが操作する守護者候補 |
| 体力 | 戦闘上の生存状態 |
| 世界耐久 | 全員で共有する世界の残存値 |
| 世界損傷 | 自分の行動で世界へ与えた累計損傷 |
| 実効世界再生 | 実際に減っていた世界耐久を回復した量 |
| 世界律 | 試合開始時に公開される、今回の世界反応一式 |
| フィールド | カードによって一時的に変更される全体規則 |
| 解放 | 強い効果を使い、世界損傷などの代償を受ける使い方 |
| 抑制 | 弱い効果または安全な処分として使う方法 |
| 戦闘勝者 | 戦闘上で生存または優位になった者 |
| 神の選定者 | 総合評価で1位になった正式な勝者 |

## 5. 体験の柱

### 5.1 破壊の誘惑

強い攻撃を使えば、相手を倒しやすい。

しかし、世界が傷つき、自分の評価が下がり、世界反応によって戦況も悪化する。

### 5.2 守るための犠牲

世界を回復する行動は、無料にしない。

体力、手札、攻撃機会、防御力などを支払わせる。

### 5.3 相手の責任を読む

相手の世界損傷が増えるほど強くなるカードや、破壊者へ向かう世界反応を入れる。

相手がどこまで世界を壊すつもりかを読む。

### 5.4 結果に物語が残る

結果画面では、点数だけでなく、決定的だった行動を示す。

例：

```text
戦闘勝者：カイ
神の選定者：ミナ

カイは「星砕き」で戦闘に勝利。
しかし世界損傷18と破界責任により選定されなかった。

ミナは世界再生11と生存8ラウンドを評価された。
```

## 7. 一試合の流れ

### 7.1 開始

1. 今回の世界律を公開する。
2. 世界耐久と三つの境界反応を表示する。
3. 山札を作る。
4. 両者へ手札を配る。
5. 先攻を決める。
6. 最初の二手番は、即死級の組み合わせが起きない保護を検討する。

### 7.2 手番

1. 継続中の世界律とフィールドを処理する。
2. カードを1枚引く。
3. カードを1枚選ぶ。
4. 必要なら、解放または抑制を選ぶ。
5. 攻撃された側が、防御、反応、受ける、を選ぶ。
6. 戦闘結果を処理する。
7. 世界損傷と世界再生を処理する。
8. 世界境界を越えた場合、世界反応を処理する。
9. 暫定評価を更新する。
10. 終了条件を確認する。

### 7.3 終了

次のいずれかで終了する。

- 片方または両方の体力が0
- 世界耐久が0
- 10ラウンド終了
- 降参
- 切断猶予超過

終了後に、戦闘結果と神の評価を別々に確定する。

## 8. 勝敗と神の評価

### 8.1 二つの結果

**戦闘勝者**

- 相手だけが体力0なら、生存者
- 最大ラウンド時は、残り体力が多い者
- 同値なら戦闘は引き分け

**神の選定者**

- 生存、世界損傷、実効世界再生、破界責任を含む総合評価1位
- 同点なら選定は引き分け
- ランダム、入力速度、先攻で同点を崩さない

将来レートを導入する場合は、神の選定結果を正式結果として扱う。

### 8.2 初期検証式

```text
生存評価
= 生存ラウンド × 2
+ 終了時体力
+ 最後まで生存した場合 40

世界評価
= 実効世界再生 × 2
- 個人世界損傷 × 3
- 破界責任 25

神の評価
= 生存評価 + 世界評価
```

数値は完成値ではない。

最初は、次の関係を作るための検証値として使う。

- 通常は生存者が有利
- 小さな世界損傷なら、生存の価値を上回らない
- 極端な世界破壊では、死亡者が選ばれる可能性がある
- 回復だけで簡単に生存者を逆転できない

### 8.3 目標分布

| 結果 | 仮の目標 |
|---|---:|
| 戦闘勝者と選定者が同じ | 75〜85％ |
| 戦闘勝者と選定者が異なる | 15〜25％ |
| 世界崩壊で終了 | 5〜15％ |
| 最大ラウンドで終了 | 10〜25％ |

分布が範囲外でも直ちに失敗とはしない。試合内容と納得感を合わせて判断する。

### 8.4 点数稼ぎへの対策

- 回復しても、過去の世界損傷記録は消えない。
- 世界耐久が実際に減っている分だけ再生点を記録する。
- 損傷1の減点は、再生1の加点より重くする。
- 世界耐久が満タンなら再生点を得られない。
- 同じカードを循環させる効果には回数制限を置く。
- 世界を0にした本人へ破界責任を与える。

## 9. 世界律

### 9.1 世界律の役割

世界律は、試合ごとに世界の性質を変える。

世界耐久75、50、25で発生する三つの反応を、試合開始時にすべて公開する。

これにより、世界を傷つける時期を読む駆け引きを作る。

### 9.2 最初の世界

**砕けゆく原初界**

- 75以下：最も世界を傷つけた戦士の次の防御値－2
- 50以下：直前に世界を再生した戦士はカードを1枚引く
- 25以下：世界損傷を伴うカードは、使用者にも2ダメージ

最小確認版では、この一つだけを使う。

### 9.3 完成品質確認版の世界候補

**反響する鏡界**

- 世界を傷つけた力が、使用者へ小さく反射する
- 一度に大きく壊す行動を抑える

**飢えた樹海界**

- 世界再生を行うと、両者の手札や体力にも影響する
- 無条件の回復を許さない

**止まりかけた時環界**

- フィールドの残り時間や手番順へ影響する
- 説明が複雑になりやすいため、三番目に検証する

世界ごとにカードを別物にせず、同じカードの価値が変わる構成を目指す。

## 10. カード構造

### 10.1 二軸で分類する

**戦闘上の役割**

- 攻撃：体力、手札、次の行動へ不利益を与える
- 防御：防ぐ、減らす、受け流す、反射する
- 介入：回復、交換、確認、条件変更などを行う
- フィールド：全員へ一定期間影響する

**世界への影響**

- 再生
- 中立
- 損傷

### 10.2 カード表示

カード上では、次の順に読む。

1. カード名
2. 戦闘上の役割
3. 自分の手番で使った結果
4. 防御または抑制で使った結果
5. 世界への損傷または再生
6. 条件と対象

一枚の文章を長くしすぎない。

主要効果は一つ、付随効果は一つまでを基本にする。

### 10.3 解放と抑制

世界損傷が大きいカードには、原則として抑制方法を持たせる。

例：

```text
星砕き
攻撃／世界損傷

解放：相手へ16ダメージ。世界損傷7。
抑制：今回の攻撃を3防御。世界影響なし。
```

抑制は常に強い選択にしない。

手札事故を防ぎつつ、解放する誘惑を残す。

### 10.4 防御時の判断

攻撃された側は、原則として次から選ぶ。

- 防御カードを1枚使う
- 反応カードを使う
- ダメージを受け、手札を温存する

最初の試作では、防御の連鎖を最大1回にする。

反射へさらに反射を重ねる処理は入れない。

### 10.5 初期の戦い方

共有山札のため、事前に戦い方を固定しない。

試合中の手札から、次の傾向が一時的に生まれる。

- **征服型**：世界損傷を受け入れ、短期撃破を狙う
- **守界型**：防御と再生で評価を積み上げる
- **制裁型**：相手の世界損傷を条件に強くなる
- **贖罪型**：一度壊した後、自分を削って回復する

どの傾向にも、明確な弱点と対抗手段を持たせる。

## 11. 内容量

### 11.1 段階別カード数

| 段階 | カード種類 | 山札総数の目安 | 世界律 |
|---|---:|---:|---:|
| 最小確認 | 12 | 30〜36 | 1 |
| オフライン試作 | 24 | 60〜72 | 1 |
| 完成品質確認版 | 36 | 72〜90 | 3 |
| 限定公開候補 | 48 | 90〜120 | 4 |

### 11.2 12種類の確認項目

- 中立攻撃
- 破壊攻撃
- 中立防御
- 破壊防御
- 再生防御
- 自己犠牲再生
- 相手の破壊を罰するカード
- 破壊フィールド
- 再生フィールド
- フィールド上書き
- 手札交換
- 解放と抑制

個別の名前より、必要な判断が一通り存在することを優先する。

### 11.3 48種類へ増やす条件

次を満たすまで増やさない。

- 24種類で処理順が安定している
- 使用率の低いカードの理由が分かる
- 似た役割のカードを整理できている
- 世界評価が勝敗へ適切に影響している
- 新しいカードが、既存カードの数値違いだけになっていない

## 12. 初心者向け導入

### 12.1 初回体験

初回は、3分程度の短いCPU戦にする。

1. 中立攻撃を使う
2. 攻撃を防御する
3. 世界損傷カードを解放する
4. 世界反応を見る
5. 再生カードを使う
6. 戦闘勝者と選定者の違いを見る

長い説明を先に読ませない。

操作した直後に、必要な一文だけを表示する。

### 12.2 初回後

- すぐCPU通常戦へ進める
- 合言葉ルームを作れる
- 共有リンクを一押しでコピーできる
- ルール詳細は任意で開ける

### 12.3 理解確認

初回終了時に、試験のような質問を出さない。

代わりに結果画面で、次の因果を強調する。

```text
あなたは生存しました。
しかし世界損傷が大きく、神の評価で敗れました。
```

## 13. 画面設計

### 13.1 優先順位

一画面で最も重要なのは、次の順である。

1. 今、自分が何を選ぶ必要があるか
2. 相手と自分の体力
3. 世界耐久と次の世界反応
4. 自分の手札
5. 個人別の世界損傷と再生
6. 現在のフィールド
7. 詳細な履歴

すべてを同じ大きさで表示しない。

### 13.2 基本構成

```text
┌────────────────┐
│ 相手：体力／手札枚数／評価傾向 │
├────────────────┤
│ 世界耐久と世界の変化            │
│ 次の世界反応                    │
├────────────────┤
│ 使用カードと解決結果            │
├────────────────┤
│ 自分：体力／損傷／再生          │
│ 手札                            │
│ 決定／取り消し                  │
└────────────────┘
```

### 13.3 危険な操作

大きな世界損傷を伴う解放には確認を出す。

```text
相手へ16ダメージ
世界へ7損傷
あなたの世界損傷 12 → 19
予想選定順位 1位 → 2位

解放しますか？
```

確認は危険なカードだけに限定し、通常操作の速さを損なわない。

## 14. 美術と音

### 14.1 美術の中心

世界を、背景ではなく主役の一つとして扱う。

- 安定：生命と建造物が存在する
- 亀裂：空と地面が割れる
- 荒廃：遠景が失われる
- 崩壊寸前：形、音、文字周辺まで不安定になる
- 再生：同じ背景の色戻しだけでなく、生命や構造が戻る

### 14.2 最初に作る演出

すべてのカードへ固有演出を作らない。

最初は次の代表演出を完成させる。

- 中立攻撃
- 大規模な世界損傷
- 防御成功
- 世界再生
- フィールド上書き
- 世界境界反応
- 終末審判
- 神の選定

### 14.3 音

- 効果音は設定で切り替えられる
- 無音でも進行と結果を理解できる
- 世界が傷つくほど環境音が減る
- 再生時に環境音が戻る
- 選定時は戦闘音を止め、査定へ注意を向ける

## 15. 再戦と継続

### 15.1 最初から入れる

- 同じ相手との再戦
- 合言葉と共有リンク
- 結果の共有文
- 結果称号
- 発見済みカード図鑑

### 15.2 後から検討する

- 同じ初期条件で挑む「本日の神託」CPU戦
- 世界律の期間限定入れ替え
- カード裏、称号、枠などの見た目報酬
- 合言葉大会
- 観戦とリプレイ共有

### 15.3 入れない成長

- 遊んだ回数でカード性能が上がる
- 課金者だけが強いカードを使える
- 所持カード差で共有山札の公平さが崩れる

## 16. 結果称号

称号は勝敗の代わりではなく、試合の物語を要約する。

候補：

| 条件 | 称号例 |
|---|---|
| 生存し、世界損傷が少ない | 守界者 |
| 生存したが大きく破壊 | 破界の勝者 |
| 死亡したが選定された | 殉界者 |
| 大きく壊し、大きく回復 | 贖罪者 |
| 相手の破壊を罰して勝利 | 審罰者 |
| 世界を0にした | 終末の執行者 |

称号は結果共有に使えるよう、短くする。

## 17. 計測する指標

数値は利用者を評価するためではなく、ゲームの問題を見つけるために使う。

### 17.1 遊びの指標

- 初回導入の完了率
- 最初のCPU戦の完了率
- 合言葉対戦の開始成功率
- 一試合の時間
- 再戦率
- 世界崩壊率
- 戦闘勝者と選定者が異なる率
- 解放と抑制の使用率
- カードごとの使用率
- 降参、時間切れ、切断率

### 17.2 理解の指標

試遊では、次を記録する。

- 結果表示前に選定者を予想できたか
- 敗因を説明できたか
- 世界の状態が選択を変えたか
- 最も迷った手番が存在したか
- もう一戦したいか

### 17.3 仮の品質目標

| 項目 | 仮の目標 |
|---|---:|
| 初回CPU戦完了 | 80％以上 |
| 対戦開始後の完了 | 85％以上 |
| 結果理由を説明できる | 試遊者80％以上 |
| 世界が選択を変えた | 試遊者70％以上 |
| 同じ相手との再戦 | 40％以上 |
| 実質的な選択がない手番 | 5％未満 |
| 先攻選定率 | 47〜53％を目標 |

少人数試遊では割合が大きく揺れる。数字だけで公開判断をしない。

## 18. 試遊の進め方

### 18.1 最小確認

- 参加者：開発側を含む3〜5人
- カード：12種類
- 目的：迷いが生まれるか

### 18.2 オフライン試作

- 参加者：5〜10人
- カード：24種類
- 目的：処理順、採点、手札事故

### 18.3 完成品質確認

- 参加者：10〜20人
- カード：36種類
- 世界律：3種類
- 目的：初心者理解、演出、再戦

### 18.4 限定公開

- 参加者：招待した利用者
- カード：48種類
- 目的：通信、費用、端末差、継続性

試遊者数を達成目標にはしない。必要な問題が見つかるまで繰り返す。

---

## 19. 多人数戦

1対1を、そのまま人数だけ増やさない。

### 19.1 2対2

- チームの戦闘結果
- 個人の世界責任
- 味方を助けるか、自分の評価を守るか

この矛盾を中心に、別ルールとして設計する。

### 19.2 3〜4人個人戦

- 早期脱落者を長く待たせない
- 集中攻撃を抑える
- 世界損傷の責任を全員が理解できる
- 一試合を複数の短い審定に分ける

1対1の配点とカードを、そのまま流用しない。

---

## 20. 権利と名称

- 既存作品のカード名、文章、効果の組み合わせ、画面を流用しない。
- 神話的な一般語だけで独自性を判断しない。
- 公開前に、タイトル、ロゴ、主要用語の同名作品と商標を確認する。
- 画像、音、フォントの利用条件を記録する。
- 生成物を使う場合も、元素材と利用条件を確認する。

「選ばれたん」の名称確認は、現時点では完了していない。

---

## 21. 実装へ進む条件

### 21.1 12種類から24種類へ進む条件

- 解放か抑制かで実際に迷う
- 世界損傷が次の判断へ影響する
- 回復が単なる得点ボタンではない
- 結果を手計算で説明できる

### 21.2 24種類から36種類へ進む条件

- 無限循環がない
- 生存者と選定者が異なる結果に納得できる
- 先攻差が極端ではない
- 一試合が長すぎない
- 似た役割のカードを整理できている

### 21.3 オンラインへ進む条件

- 初心者が説明なしで主要操作を完了できる
- 結果理由を理解できる
- 再戦したいという反応が確認できる
- 世界3種類でカード価値が変わる
- iPhone縦画面で見切れない

---

## 22. 大幅再設計する条件

次の状態が続く場合は、カード追加や通信実装を止める。

- 世界評価を無視して相手を倒すことが常に最善
- 世界再生を繰り返すことが常に最善
- 強力カードを抑制する理由がない
- 最終評価が毎回予想外で、不満になる
- 最終評価が戦闘結果をほとんど変えない
- 24種類でも試合展開がほぼ同じ
- 世界の見た目が変わっても、戦闘判断は変わらない
- 一戦で十分だと感じる試遊者が多い

---

## 23. 完成品質確認版の定義

36種類、世界律3種類を使い、次を一つの流れで体験できる状態を目標とする。

1. 初回導入
2. CPU戦
3. 世界の損傷と再生
4. 神の評価
5. 結果称号
6. 再戦
7. 合言葉ルーム作成の入口

オンライン通信が未完成でも、作品の魅力を一試合で説明できることが必要である。

## 24. 限定公開版の定義

- カード48種類
- 世界律4種類
- CPU難易度3段階
- 合言葉1対1
- 切断復帰
- 再戦
- 結果共有
- 設定と操作説明
- 費用と通信量の計測
- 重大な進行停止がない

公開マッチング、レート、ランキングは含めない。

## 25. 最終判断

本作の価値は、環境保護の正しさを教えることではない。

> 自分が生き残るために世界を傷つけるか、自分を危険にさらして世界を守るかを、相手との戦闘の中で選ばせること。

その判断が手札、世界律、相手の責任、最終評価へつながるとき、本作は独自の対戦ゲームになる。
