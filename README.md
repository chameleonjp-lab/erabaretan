# 選ばれたん

神に選ばれた戦士たちが、世界へ影響を及ぼしながら、生存と神の評価を競う対戦カードゲームです。

相手を倒しただけでは、正式な勝者になれるとは限りません。戦闘中に世界へ与えた損傷と、世界の回復に貢献した量も、最後の神の審判で査定されます。
