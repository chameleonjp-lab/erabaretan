# エラバレタン：P1-03 game-core 世界境界・終端・採点実装記録 V1

## 1. 位置づけ

P1-03では、P1-02の効果キューへ、alpha-12の世界律、フィールド自動効果、カード条件、正常終了、神の評価を接続した。

画面、通信、保存、実時間、乱数は参照しない。世界律の反応と追加効果も、元の解決単位の上限32件へ含める。

## 2. 実装範囲

### 世界境界

- 世界が境界より上から境界以下へ下がったときだけ、75・50・25を発生済みへ記録する。
- 解決単位の末尾で、新しく発生した境界を75→50→25の順に処理する。
- 75は、解決単位の最終的な世界損傷責任を比較し、単独最高へ2、同率最高へ1の`nextDefensePenalty`を付ける。
- 50は、その解決単位で最後に実効世界再生を行ったプレイヤーへ、手札と山札に余裕がある場合だけ1枚引かせる。
- 25は、反応処理後から脆い世界を有効化する。以後の世界損傷カードは、実効世界損傷が1以上なら使用者へ2の通常ダメージを1回だけ返す。
- 25境界を越えたカード自身には自己損傷を付けず、複数の`DAMAGE_WORLD`命令を持つ同一カードにも重複させない。

### フィールド

`ActiveFieldState`へフィールド固有の使用記録を持たせた。

- `field.frenzied-fracture.v1`は、解放カード1枚につき最初の世界損傷要求へ1を加える。
- `field.root-sanctuary.v1`は、各`turnSequence`の最初の世界損傷要求だけ2を減らす。
- 新しいフィールドは旧フィールドを上書きし、`CLEAR_FIELD`後の同じカードの損傷へ旧フィールドを適用しない。
- `advanceTurnSequence`は、期限前のフィールドを保持し、期限到達前に期限切れフィールド・盾・一時修正を除去する。
- rulesetの`fieldDefinitionIds`へ存在しないフィールドは効果命令として拒否する。

### カード条件

初期12種類の定義へ`introducedRulesetId`とモード別の宣言的条件を追加した。

- 再生の誓約：体力5以上、世界が最大未満。
- 傷痕への審罰・解放：対象者の世界損傷責任5以上。
- 無色の宣告：有効なフィールドが存在する。
- 静かな手直し：解決中カードを含めて手札2枚以上。
- 全カードの行動段階、応答者、対象者、対応モードを検証する。

`initial12CommandValidationOptions`を`applyCommand`へ渡すことで、汎用command検証へカード正本の条件を接続できる。game-core自体はcontentへ依存しない。

## 3. 正常終了と採点

全効果と世界律反応後に、体力0、世界0、最大ラウンドを確認する。世界0と体力0は同時に記録し、破界責任者へ25の採点修正を一度だけ記録する。

正常終了では、次を計算する。

```text
生存評価 = survivedRoundCount × survivalRoundScore + 終了時体力 + 生存ボーナス
世界評価 = effectiveWorldRestore × worldRestoreScoreMultiplier
          + worldDamageResponsibility × worldDamageScoreMultiplier
          - 破界責任
神の評価 = 生存評価 + 世界評価
```

降参、`INVALID_MATCH`などの非正常終了へ神の評価を付けない。得点同率時の`winnerId`は`null`とする。

## 4. 検証

実行コマンド：

```text
node --experimental-strip-types --test tests/game-core/*.test.mjs tests/content/*.test.mjs
```

P1-02の23件に、P1-03の世界境界、フィールド、自己損傷、終端、採点、カード条件を加え、37件が成功することを確認した。

主な固定値：

- 通常撃破：P1 72点、P2 2点。
- 世界80から0：P1 -193点、P2 2点。
- 反射・同時撃破・世界崩壊：P1 -113点、P2 2点。
